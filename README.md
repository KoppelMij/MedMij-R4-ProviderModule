# MedMij-R4-KoppelMij
This repository contains HL7 FHIR R4 compliant conformance materials for MedMij R4 Tasks, Activity Definitions and Endpoints for the dataservice ProviderTasks. This dataservice will be used in the projects ‘Koppelmij’ and ‘Persoonsgerichte Hybride Netwerkzorg’ . This project is currently in a pre-publication status and can therefore not be considered stable.

The implementation guide for this project, also in a pre-publication status, can be found on (https://simplifier.net/medmij-r4-provider-module/~introduction).

This repository is maintained by MedMij.
